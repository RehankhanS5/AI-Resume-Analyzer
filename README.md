# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that evaluates a candidate's resume against a job description and provides ATS-style insights, including compatibility scoring, skill matching, keyword analysis, and resume improvement recommendations.

The project is designed to help job seekers understand how well their resume aligns with a target role and identify areas that can be improved.

---

## 📌 Project Overview

Recruitment systems often use Applicant Tracking Systems (ATS) to screen resumes based on relevant skills, keywords, experience, and job requirements.

The **AI Resume Analyzer** analyzes resume content against a provided job description and generates an easy-to-understand analysis dashboard.
